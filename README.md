# IndAMR

Open, reproducible analysis of antimicrobial resistance (AMR) genes in publicly available Indian bacterial genomes.

> 🇮🇳 सार्वजनिक भारतीय जीवाणु जीनोम में रोगाणुरोधी प्रतिरोध जीनों का खुला, पुनरुत्पादनीय विश्लेषण।
> ଭାରତୀୟ ଜୀବାଣୁ ଜିନୋମରେ ଆଣ୍ଟିମାଇକ୍ରୋବିଆଲ ପ୍ରତିରୋଧ ଜିନର ଖୋଲା, ପୁନଃଉତ୍ପାଦନଯୋଗ୍ୟ ବିଶ୍ଳେଷଣ।

## Why
India carries one of the world's highest burdens of drug-resistant infections, but genomic AMR data from Indian isolates is scattered and unevenly annotated. IndAMR aims to make that data easier to explore, audit and reuse.

## Status
🚧 Early development. First release (v0.0.1) planned for December 2026.
