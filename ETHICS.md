# Ethics and data use

- **Public data only.** IndAMR uses only openly released genomic data and metadata from NCBI. No new samples are collected.
- **No personal data.** No patient identifiers are used or stored. Location data is kept at country/state level only.
- **Not for clinical use.** Outputs are for research and education. They must not guide treatment decisions.
- **Known biases.** Public genomes over-represent certain hospitals, pathogens and outbreaks. Results describe the available data, not true prevalence in India.
- **Credit.** All data sources are cited, and the original submitters' work is acknowledged.
